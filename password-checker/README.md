# Password strength checker 
A simple python program that checks password strength based on :
  - Minimum length (8 characters )
  - Uppercase letters
  - Lowercase letters
  - Numbers 
  - Symbols
# How it works 
The program analyzes the entered password and provides feedback on missing requirements .
It aslo gives a final strength rating
